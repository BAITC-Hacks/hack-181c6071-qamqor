# Правила AI-исполнителей

Кейс #79-lite и `docs/CASE.md` — источник продуктовых требований. AI исполняет и отлаживает решения команды, но не придумывает новые функции или бизнес-правила.

- Не добавлять бронирование, заявки, уведомления, marketplace или обучение модели.
- Детерминированную фильтрацию и ранжирование выполнять кодом. LLM использовать только для конкретного объяснения по уже рассчитанным факторам.
- Один запрос обязан давать одинаковый порядок даже при недоступном API.
- Не отправлять секреты, персональные данные и `.env.local` в Git.
- Не менять чужую зону, общие типы или зависимости без решения Али.
- После изменения показывать diff, команды проверки и известные ограничения.

Зоны: Али — core/integration/deploy; Даурен — UI; Димаш — data/explanations/QA/README.
