# Выжимка официальных инструкций

- Решается один выбранный кейс; все кейсы трека решать не требуется.
- За пять часов реализуется обязательный сценарий от входа до результата.
- Каждый участник обязан внести личный вклад.
- Итог находится в выданном GitHub repo и сдаётся дополнительной кнопкой «Сдать решение».
- README должен описывать функции, архитектуру, запуск, проверку, данные, интеграции, ограничения и deployed URL.
- API-ключи, токены и `.env.local` запрещено размещать в GitHub, презентациях и чатах.
- Используется только официальная сеть; личные hotspots/модемы запрещены без разрешения.
- Не сканировать сеть, не проводить нагрузочные или атакующие проверки.
- Последний час все участники находятся в зоне; личные выходы за день суммарно до 60 минут с отметкой у стюарда.
- Если ключ раскрыт, немедленно отозвать его и сообщить организаторам/штабу безопасности.

Курс Arizona State University не является частью технического MVP кейса.
