# AI-1: серверные объяснения

Существующий `/api/match` сначала вызывает matcher, затем `improveExplanations`.
Отбор, ID, порядок, score, facts, message и rejectionSummary модель не меняет.
Максимум три результата. Ключ берётся только из `process.env.OPENAI_API_KEY`;
модуль импортируется серверным route и использует Node-only API.
Ответ API всегда содержит `explanationMode`: `ai` после принятого ответа модели,
`fallback` при любом fallback, включая отсутствие ключа и пустую выдачу.

Один POST в OpenAI Responses API, модель `gpt-4o-mini`, `store: false`, без retry.
Передаются только явно перечисленные поля запроса и факты выбранных кандидатов
(ID, доступность на дату, цена от, остаток бюджета, формат, язык, часы).
Имена, полные профили, описания, score и произвольные дополнительные поля не передаются.
Формат сверён с [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

Модель получает также только короткий признак, извлечённый из официальной анкеты
по фиксированным правилам (например, стаж или упоминание импровизации), без полного
текста описания. Этот признак добавляется в итоговое объяснение без изменения моделью.

Модель выбирает акцент (формат, подтверждённый язык или длительность), вариант
формулировки и способ объяснить бюджет. Ответ — строгий JSON-план, не свободный
текст. Код собирает два предложения только из исходных фактов. Это сознательное
ограничение: модель не может приписать опыт, отзывы, скидки или другие свойства.
Проверяются полный набор уникальных ID, допустимые поля/значения и наличие фактов
для выбранного акцента. Порядок ответа модели не влияет на порядок карточек.

Fallback возвращает все исходные объяснения matcher при отсутствии/пустом ключе,
сетевой/HTTP-ошибке, отказе, незавершённом ответе, неверном JSON/плане, лишнем или
пропущенном ID, ответе больше 32 КиБ или таймауте. Пустая выдача не вызывает API.
Общий таймаут 3500 мс охватывает fetch и чтение тела; Promise.race ограничивает
ожидание, AbortController отменяет запрос. Ошибки и ответы провайдера не логируются.

## Проверки

Из корня, на Node.js 25.2.1 (нативная поддержка TypeScript):

```shell
npm run check
npm run build
node --test tests/matching.test.mjs
node --test tests/ai-explanations.test.mjs
```

AI-тесты используют официальный CSV, настоящий matcher и подменяют только fetch
и тестовое значение env. Реальный ключ и платные запросы не нужны. Проверяются
успех, неизменность результата кроме explanation, минимальный payload, ошибки,
недостоверные планы, отказ, таймаут fetch и тела, отсутствие retry и лимит три.

Ограничения: без настроенного серверного ключа приложение работает с шаблонными
объяснениями. Живой OpenAI-вызов этими тестами не проверяется; доступность модели
для конкретного аккаунта и качество выбора формулировок требуют отдельного smoke
test с ключом в окружении. Тексты могут отличаться между успешными AI-запросами,
но ID и порядок всегда задаёт matcher. UI и схема внешнего API не изменены.
