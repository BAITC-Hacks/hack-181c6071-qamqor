# Qamqor Match — умный подбор event-подрядчиков

Решение команды Qamqor для кейса #79-lite трека «Креативные индустрии» от Firebird.

Сервис принимает город, дату, формат мероприятия, категорию и бюджет, затем возвращает до трёх доступных подрядчиков с конкретными объяснениями выбора. Дополнительно учитываются язык и длительность. Один запрос всегда даёт одинаковый порядок.

## Статус

Рабочий MVP опубликован: [qamqor-hackathon.vercel.app](https://qamqor-hackathon.vercel.app).

Реализованы загрузка официального датасета, детерминированный подбор, API и интерфейс с объяснениями результата.

## Обязательный результат

- занятые на выбранную дату подрядчики исключаются;
- бюджет, формат, город, категория, язык и длительность проверяются явно;
- показывается не более трёх карточек;
- каждое объяснение содержит конкретные факторы, а не общую похвалу;
- различаются три исхода: варианты найдены, категории нет в городе, кандидаты есть, но не проходят фильтры;
- одинаковый запрос сохраняет порядок результатов;
- ответ формируется менее чем за 10 секунд.

## Запуск

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию — `http://localhost:3000`. Проверки перед отправкой изменений:

```bash
npm run check
npm run build
```

## Данные

`data/hackathon-dataset-anonymized.csv` — официальный набор из 66 профилей. Источник указан в `docs/CASE.md`. Синтетические профили, если будут добавлены, помечаются `synthetic: true` и визуально отличаются в демо.

## Секреты

Реальные значения хранятся только в `.env.local` и Vercel Environment Variables. `.env.local` не коммитится.
